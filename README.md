## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executor tools bundled with a universal loader (xcutorsLoader), making it easy to manage and switch between multiple executors from a single interface.

### Is XCutors free to use?

Yes, XCutors and the universal loader are completely free and open-source. Some individual executors included in the collection may have their own separate licensing or premium tiers.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Earlier versions such as Windows 7 or 8 are not officially supported and may experience compatibility issues.

### Why does my anticomponent flag the loader?

Script executors use process memory techniques that are heuristically flagged by anticomponent engines as potentially unwanted programs. You can add a folder exclusion for your XCutors directory. Always download only from the official GitHub repository.

### How do I update the executors?

The built-in auto-update system checks for new versions each time you launch xcutorsLoader. You can also manually trigger an update check from the Settings menu inside the loader.

### Can I use multiple executors at the same time?

Only one executor can be injected into a single Roblox process at a time. To switch, detach the currently active executor and then inject a different one from the dashboard.

### Where can I find scripts to use?

XCutors includes a built-in script hub with curated and categorized scripts. You can also browse community scripts from popular Roblox scripting forums, GitHub repositories, and Discord communities.

### What should I do if injection fails?

Ensure Roblox is fully loaded before injecting, run the loader as Administrator, and check that your anticomponent is not blocking the process. Restarting both Roblox and the loader usually resolves most connection issues.

### Is XCutors open source?

The universal loader (xcutorsLoader) is fully open source and available in this repository. Individual executors are third-party tools with their own source availability and licensing terms.

### Does XCutors work with Roblox UWP (Microsoft Store version)?

XCutors is designed for the standard Roblox desktop client. Compatibility with the UWP/Microsoft Store version is not guaranteed and may require additional configuration.
